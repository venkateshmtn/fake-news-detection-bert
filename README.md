\# 📰 Fake News Detection using BERT



This project uses a BERT-based deep learning model to classify news articles as Fake or Real.



\## 🚀 Features

\- BERT (bert-base-uncased)

\- Tokenization using Hugging Face

\- Streamlit web app

\- End-to-end NLP pipeline



\## 🛠️ Tech Stack

\- Python

\- PyTorch

\- Transformers

\- Streamlit



\## ▶️ Run

pip install -r requirements.txt  

streamlit run app.py
